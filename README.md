# Loan-Approval-System
📌 About the Project
The Loan Approval Prediction System is a beginner-friendly machine
learning project that predicts whether a loan application is likely to
be approved or rejected. It uses four applicant details: income,
requested loan amount, credit history, and employment type.

Three classification algorithms are implemented and compared to
understand how different models perform on the same prediction task.
Important: This project uses 60 manually created fictional records
for educational purposes. It is not trained on real bank records and
must not be used to make actual lending decisions.

🎯 Objectives
- Understand the workflow of a machine learning classification
  problem.
- Prepare and encode a dataset for model training.
- Build and compare three classification algorithms.
- Evaluate model performance using standard metrics.
- Predict the outcome for a new applicant.
- Visualize the trained Decision Tree.
🤖 Machine Learning Algorithms
  Algorithm                           Description
  Decision Tree                   Learns decision rules from
applicant details.

  k-Nearest Neighbors (k-NN)      Predicts a class based on nearby
training examples.
Random Forest                   Combines multiple decision trees to
make a prediction.
The k-NN model uses feature scaling because distance-based algorithms
are sensitive to differences in feature ranges. Different values of k
are compared using a simple validation approach.
📊 Dataset
The notebook contains 60 fictional records, four input features, and
one target column.

🧰 Technologies Used
